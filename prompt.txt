You are a senior full-stack developer. I want you to design and help build a production-level MVP web application using modern best practices. Think like a startup engineer, not a tutorial coder.

# 🧠 Project Overview

We are building a platform similar to LinkedIn/Indeed but focused ONLY on internships. The goal is to create a fast, clean, and highly optimized system where:

* Students can find internships easily
* Companies can post internships and find candidates
* Matching is based on skills, level, and preferences

This is NOT a generic job board. It should feel smart, lightweight, and focused.

---

# 🏗️ Tech Stack (STRICT)

* Frontend: Next.js (App Router, latest version)
* Backend: Next.js API routes (no separate backend for MVP)
* Database: MongoDB (optimized schema, minimal storage usage)
* Auth: NextAuth with Google OAuth ONLY (no password system initially)
* Storage: Cloudinary (for images and PDFs)
* Deployment-ready structure (Vercel compatible)

---

# ⚡ Core Requirements

## 🔐 Authentication

* Google OAuth login
* On first login:

  * Store email, name, profile image
  * Redirect to profile completion
* Allow user to EDIT name and set:

  * username (unique)
  * role (student or company)

## 📦 File Handling

* Use Cloudinary
* Accept uploads up to ~1MB
* Compress automatically:

  * Resize max 800px
  * Convert to WebP
  * Target ~130KB per image
* PDFs max ~300KB
* Store ONLY URLs in database
* Do NOT store profile images (use Google image URL)
